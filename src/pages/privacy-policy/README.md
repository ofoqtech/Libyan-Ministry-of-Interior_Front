# صفحة سياسة الخصوصية - Privacy Policy Page

## الوصف
صفحة سياسة الخصوصية لموقع وزارة الداخلية بالحكومة الليبية، تدعم اللغتين العربية والإنجليزية مع تصميم جميل ومناسب لموقع الوزارة.

## المميزات
- ✅ دعم اللغتين العربية والإنجليزية (i18n)
- ✅ تصميم جميل ومناسب لموقع الوزارة
- ✅ متجاوب مع جميع الأجهزة (Responsive Design)
- ✅ دعم RTL للعربية و LTR للإنجليزية
- ✅ تأثيرات بصرية جميلة (Animations)
- ✅ CSS Module للتصميم
- ✅ لا يحتوي على أرقام هواتف أو بريد إلكتروني

## الملفات
- `PrivacyPolicy.jsx` - المكون الرئيسي للصفحة
- `PrivacyPolicy.module.css` - ملف CSS Module للتصميم
- `index.js` - ملف التصدير

## الاستخدام
تم ربط الصفحة بالـ Footer ويمكن الوصول إليها من خلال:
- رابط "سياسة الخصوصية" في Footer
- المسار: `/privacy-policy`

## التصميم
- خلفية متدرجة جميلة
- ألوان مناسبة لموقع الوزارة
- تأثيرات حركية عند التمرير
- تصميم متجاوب مع جميع الشاشات
- دعم كامل للغتين مع تغيير الاتجاه

## الترجمة
تم إضافة جميع النصوص باللغتين في ملفات الترجمة:
- `src/translations/ar/global.json`
- `src/translations/en/global.json`
